# Running a payroll period

Go to the Payroll Runs page from the sidebar. Click New Run, pick the Year and Month, and click Create to open the period; you are taken to the new run's detail page.

On the run detail, work through the steps in order: Calculate to compute the payslips, Approve to lock the run, Post to write the journal entries to accounting, and Pay Net Salaries to settle payment.

Use the Payslips list to see each employee's gross, deductions, and net; click the payslip icon on a row to open that employee's payslip.
