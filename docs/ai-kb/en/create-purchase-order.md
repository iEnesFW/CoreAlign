# Creating a purchase order

Open the Purchase Orders page from the sidebar and click New PO. In the dialog, select the vendor, set the currency, order date and Expected delivery date; choose the delivery warehouse if needed.

Use Add line to add products, enter the quantity, unit cost and VAT % for each line, then click Save to create the order as a draft. From the list, send it with Submit and confirm it with Approve; an approved order is ready to be received with Receive.
