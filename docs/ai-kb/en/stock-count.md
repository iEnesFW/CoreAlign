# Performing a stock count

Open the Stock Counts page from the sidebar and click New Count. In the Plan New Count dialog, select the Warehouse, optionally add Notes, and click Create Count to plan it; all stock items of the selected warehouse are written to the count lines as a snapshot.

Click the count number in the list to open its detail, then use Start Count to begin counting. Enter each line's Counted quantity, save with Save Counts; once every line is entered, optionally add Reconciliation Notes and click Reconcile.

Process a count in Reconciliation status with Post Count to post and confirm it. This writes the variance lines as stock movements and cannot be undone.
