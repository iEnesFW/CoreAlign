# Creating and confirming a sales order

Go to the Orders page from the sidebar. Click New order, choose the Customer, then set the Currency, Order Type and commercial terms. On the Line Items tab use Add line to enter the product, quantity and unit price; review the Grand Total and click Save. The new order is created as a Draft.

To decrement stock, confirm the order: open it, set the Status field to Confirmed, and click Save. Confirming an order decrements stock from the default warehouse. Alternatively, from the order row you can run the warehouse/shipment flow with Submit → Approve → Allocate stock.
