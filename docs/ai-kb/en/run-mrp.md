# Running an MRP plan

Open the MRP Workbench page from the sidebar. Choose the Bucket (Day/Week) and Horizon, then click Run preview to compute the time-phased plan; on the planning grid tab review the gross requirement, scheduled receipts, projected on-hand and net requirement rows.

To confirm the preview, click Commit plan. Once the plan is committed, the action queue tab lets you select exceptions and use Release selected to release planned orders in bulk.

To release individually, click a product in the planning grid to open its pegging drawer. For Buy items, Release converts the planned order into a purchase requisition; for Make items, Create production order opens a production order.
