# Processing a return

Open the return request on the Returns page. If the status is Requested, review it and advance it with Approve, or enter a reason in the Reject Return section and click Reject.

Once the return is approved, in the Receive Return section choose the warehouse the goods will go into; leave "Automatically issue credit note" ticked if you want the credit note created on receipt, then click Receive. The returned items are taken into stock and, if the option is ticked, a credit note is issued and the request moves to CreditNoted.
