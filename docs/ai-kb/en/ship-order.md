# Shipping an order

Open the Orders page from the sidebar and select the order to ship. Work through the action bar steps in order based on the order status: Submit, Approve, then Allocate stock. Once the order is Allocated, the Create shipment button appears in the action bar.

Click Create shipment, choose the warehouse, tick the lines and quantities to ship, then confirm with Create shipment. In the Shipments tab, advance the shipment with Mark picked, Mark packed and Dispatch. When all lines are shipped the order moves to Shipped; after delivery use Mark delivered and Close order to complete it.
