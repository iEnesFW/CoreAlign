# Validation (CoreAlign UI)

"Validation" alanındaki ekran ve özelliklerde geçen terimler / terms used in the "Validation" area (English / Türkçe):

- Add at least one line. / En az bir satır ekleyin.
- Use uppercase ISO code (e.g., USD). / Büyük harf ISO kodu kullanın (örn. TRY, USD).
- Currency must be 3 characters. / Para birimi 3 karakter olmalıdır.
- Email is too long. / E-posta adresi çok uzun.
- Please enter a valid email address. / Geçerli bir e-posta adresi girin.
- Name is too long. / Ad çok uzun.
- Name must be at least 2 characters. / Ad en az 2 karakter olmalıdır.
- Cannot be negative. / Negatif olamaz.
- Organization name must not exceed 150 characters. / Organizasyon adı 150 karakteri geçemez.
- Organization name must be at least 2 characters. / Organizasyon adı en az 2 karakter olmalıdır.
- Passwords do not match. / Şifreler eşleşmiyor.
- New password must be different from the current one. / Yeni şifre mevcut şifreden farklı olmalıdır.
- Password must contain at least one digit. / Şifre en az bir rakam içermelidir.
- Password must contain at least one lowercase letter. / Şifre en az bir küçük harf içermelidir.
- Password must contain at least one special character. / Şifre en az bir özel karakter içermelidir.
- Password must contain at least one uppercase letter. / Şifre en az bir büyük harf içermelidir.
- Password must be at least 8 characters. / Şifre en az 8 karakter olmalıdır.
- Must be positive. / Pozitif olmalıdır.
- This field is required. / Bu alan zorunludur.
- Too long. / Çok uzun.
- Username can only contain letters, numbers, dots, hyphens and underscores. / Kullanıcı adı yalnızca harf, rakam, nokta, tire ve alt çizgi içerebilir.
- Username must not exceed 64 characters. / Kullanıcı adı 64 karakteri geçemez.
- Username must be at least 3 characters. / Kullanıcı adı en az 3 karakter olmalıdır.
