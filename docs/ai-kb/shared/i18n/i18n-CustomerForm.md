# CustomerForm (CoreAlign UI)

"CustomerForm" alanındaki ekran ve özelliklerde geçen terimler / terms used in the "CustomerForm" area (English / Türkçe):

- Classification / Sınıflandırma
- Code / Kod
- e.g. CUST-0001 / Örn. MUS-0001
- Commercial Terms / Ticari Koşullar
- Credit Limit / Kredi Limiti
- Currency / Para Birimi
- Customer Group / Müşteri Grubu
- Default Discount % / Varsayılan İskonto %
- e.g. info@acme.com / Örn. info@acme.com
- Legal Name / Ticari Ünvan
- e.g. Acme Technology Joint Stock Company / Örn. Acme Teknoloji Anonim Şirketi
- e.g. Acme Technology Inc. / Örn. Acme Teknoloji A.Ş.
- National ID / TC Kimlik No
- e.g. 12345678901 / Örn. 12345678901
- Payment Term / Ödeme Vadesi
- Price List / Fiyat Listesi
- New / Yeni
- e.g. 1234567890 / Örn. 1234567890
- Tax Office / Vergi Dairesi
- e.g. Kadıköy / Örn. Kadıköy
- Territory / Bölge
- Trade Name / Marka Adı
- e.g. Acme / Örn. Acme
- Business / Şirket
- Government / Kamu
- Individual / Şahıs
- Type / Tip
- Website / Web Sitesi
- e.g. https://acme.com / Örn. https://acme.com
