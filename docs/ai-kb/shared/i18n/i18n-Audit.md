# Audit (CoreAlign UI)

"Audit" alanındaki ekran ve özelliklerde geçen terimler / terms used in the "Audit" area (English / Türkçe):

- Action / İşlem
- After (JSON) / Sonrası (JSON)
- Any action / Tüm işlemler
- Apply filters / Filtreleri uygula
- Changed at / Değişiklik zamanı
- Audit entry details / Denetim kaydı detayı
- Entity ID / Kayıt ID
- Entity type / Kayıt türü
- e.g. Order, Invoice / örn. Order, Invoice
- Entity types (comma separated) / Kayıt türleri (virgülle ayrılmış)
- Audit export started / Denetim dışa aktarımı başlatıldı
- Format / Biçim
- Frequency / Sıklık
- From date / Başlangıç tarihi
- ID
- Last run / Son çalıştırma
- Lookback (days) / Geriye dönük gün sayısı
- No audit entries match the current filters. / Mevcut filtrelerle eşleşen denetim kaydı yok.
- Audit Log / Denetim Günlüğü
- Recipients (comma separated emails) / Alıcılar (virgülle ayrılmış e-postalar)
- Reset / Sıfırla
- Rolling hash / Zincir özeti (rolling hash)
- Save schedule / Zamanlamayı kaydet
- Scheduled export enabled / Zamanlanmış dışa aktarma etkin
- Export schedule saved / Dışa aktarma zamanlaması kaydedildi
- Sequence / Sıra No
- Log / Günlük
- To date / Bitiş tarihi
- {{count}} rows total / Toplam {{count}} kayıt
- User ID / Kullanıcı ID
