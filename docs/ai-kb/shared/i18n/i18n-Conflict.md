# Conflict (CoreAlign UI)

"Conflict" alanındaki ekran ve özelliklerde geçen terimler / terms used in the "Conflict" area (English / Türkçe):

- Your version / Sizin sürümünüz
- Conflicting fields / Çakışan alanlar
- Current version / Geçerli sürüm
- This record was changed by someone else while you were editing. Review the differences before continuing. / Bu kayıt siz düzenlerken başka bir kullanıcı tarafından değiştirildi. Devam etmeden önce farkları inceleyin.
- Overwrite anyway / Yine de üzerine yaz
- Resubmitting your changes with overwrite... / Değişiklikleriniz üzerine yazılarak yeniden gönderiliyor...
- Overwriting will discard the other user's changes. / Üzerine yazarsanız diğer kullanıcının değişiklikleri kaybolur.
- Reload latest / Güncel veriyi yükle
- Update conflict / Güncelleme çakışması
