# İade işleme

İadeler sayfasında ilgili iade talebini açın. Durum Talep Edildi ise talebi inceleyip Onayla ile ilerletin veya İadeyi Reddet bölümüne neden yazıp Reddet'e tıklayın.

İade onaylandıktan sonra İadeyi Teslim Al bölümünde malın gireceği depoyu seçin; alacak dekontunu otomatik oluşturmak istiyorsanız "Alacak dekontunu otomatik oluştur" kutusunu işaretli bırakın ve Teslim Al'a tıklayın. İade malı stoğa alınır ve seçenek işaretliyse alacak dekontu kesilerek talep Alacak Dekontu Kesildi durumuna geçer.
