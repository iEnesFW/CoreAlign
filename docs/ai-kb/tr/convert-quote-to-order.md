# Teklifi siparişe dönüştürme

Teklifler sayfasında bir teklif, müşteri tarafından kabul edildikten sonra siparişe dönüştürülür. Teklif yaşam döngüsü Taslak → Gönderildi → Kabul Edildi → Sipariş şeklindedir.

1. Sol menüden Teklifler sayfasına gidin.
2. Taslak (Draft) teklifi müşteriye iletmek için teklif satırındaki "Gönder" düğmesini kullanın; teklif "Gönderildi" durumuna geçer.
3. Müşteri kabul ettiğinde teklif satırındaki "Kabul Et" düğmesine tıklayın (reddetmek için "Reddet"); durum "Kabul Edildi" olur.
4. Kabul edilmiş ve henüz dönüştürülmemiş teklifte "Siparişe Dönüştür" düğmesine tıklayın.

Dönüştürme sonrası sistem yeni siparişi oluşturur ve sizi Siparişler sayfasına yönlendirir. Yeni teklif oluşturmak için sayfanın sağ üstündeki "Yeni Teklif" düğmesini kullanın.
