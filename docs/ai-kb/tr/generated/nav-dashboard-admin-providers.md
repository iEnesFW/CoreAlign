# Sağlayıcılar

Sağlayıcılar, CoreAlign uygulamasındaki bir sayfadır. Sol kenar çubuğundan (menü) "Sağlayıcılar" bağlantısına tıklayarak açılır. Adres yolu: /dashboard/admin/providers. Bu sayfaya gitmek için sol menüden ilgili bölümü ve "Sağlayıcılar" öğesini seçin.
