# Hata Kayıtları

Hata Kayıtları, CoreAlign uygulamasındaki bir sayfadır. Sol kenar çubuğundan (menü) "Hata Kayıtları" bağlantısına tıklayarak açılır. Adres yolu: /dashboard/admin/error-logs. Bu sayfaya gitmek için sol menüden ilgili bölümü ve "Hata Kayıtları" öğesini seçin.
