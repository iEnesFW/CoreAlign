# Bordro Parametreleri

Bordro Parametreleri, CoreAlign uygulamasındaki bir sayfadır. Sol kenar çubuğundan (menü) "Bordro Parametreleri" bağlantısına tıklayarak açılır. Adres yolu: /dashboard/hr/payroll-parameters. Bu sayfaya gitmek için sol menüden ilgili bölümü ve "Bordro Parametreleri" öğesini seçin.
