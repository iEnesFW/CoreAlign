# Muhasebe Dönemleri

Muhasebe Dönemleri, CoreAlign uygulamasındaki bir sayfadır. Sol kenar çubuğundan (menü) "Muhasebe Dönemleri" bağlantısına tıklayarak açılır. Adres yolu: /dashboard/accounting/periods. Bu sayfaya gitmek için sol menüden ilgili bölümü ve "Muhasebe Dönemleri" öğesini seçin.
